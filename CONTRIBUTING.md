# Contributing

1. Fork, branch, make your change.
2. `pip install -r requirements-playwright.txt` (or `-selenium` / `-puppeteer`) and run `python3 smoke_test.py` — it must pass with **no** engine installed at all, so if you're only testing one engine, that's still a meaningful run.
3. **If you touched `page_parser.py`: this is the important one.** No real capture of a rendered perplexity.ai Page exists anywhere in this repo's history yet (see that file's module docstring — direct HTTP access to perplexity.ai is blocked from every automated shell this repo was built in; only research through `robots.txt`, the sitemap, and third-party/first-party writeups was possible). Every DOM selector, the JSON-LD node-shape guess, and even the OG-meta field mapping are marked `# TODO: verify live`. If you have a real, scrubbed `--dump-html` capture of an actual Page, save it under `tests/fixtures/`, update `page_parser.py` to match, and remove the `# TODO` for whatever you just confirmed — that turns a guess into this repo's first actually-verified site knowledge. Don't remove a `# TODO` without a capture backing it up.
4. Keep the three engines behaving identically: same exit codes, same `Product` schema, same CLI flags. If one needs to diverge (see `selenium_scraper.py`'s CDP-credential limitation for an example), say why in a comment.
5. Open a PR. CI runs the offline suite on two Python versions plus one `engine-smoke` job per engine, each in its own virtualenv, plus a daily `canary` job that fetches one real Page with no secrets (see `TESTING.md`).

Bug reports and feature requests: open an issue. Please include the exact command you ran and the `.meta.json` sidecar from the run (or note that none was written — that's itself informative, see `output_writer.finish_run`'s docstring), not just a description. If you're reporting that a Page came back empty, attaching a `--dump-html` capture is the single most useful thing you can add — it's exactly what `page_parser.py` still needs. If you can also confirm whether perplexity.ai actually emits any JSON-LD on a Page, and what its DOM structure for the sources/citations list and the two engagement counters actually looks like, that closes several of this repo's open unknowns (see README "Read this before trusting a run").
